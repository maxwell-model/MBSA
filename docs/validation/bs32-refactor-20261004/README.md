全部计划组合已完成，无缺失、重复或记录合同违规。416 个配置对应 413 个不同 Q/KV 几何，覆盖有限清单的 416/11,328≈3.67%；每个选定配置的 48 个 MBSA 选项和 16 个原生对比选项完整展开。KV 8K–256K 的 32 个主档位、Q 边界和 P=1–32 的 mixed 族均有覆盖。decode 仅预留 8192 总调度预算，实际执行与校验只包含 prefill。

HF 固定版本为 `d97a6c52967a5ed332e2196a5b985f0b4a475549`，五个原始方法的 AST 与源文件哈希见 [HF 基准](hf-source.json)。输出门限为 `|ΔO|≤0.03+0.03|O_HF|`，自然对数 LSE 门限为 `|ΔLSE|≤0.01+0.002|LSE_ref|`，Remote block 集合必须精确一致；近似等分不豁免失败。原生接口不暴露可比 LSE，原生 gate 校验输出与路由。

合并两种 page map、每个配置只计 eager/warm/auto 一次，每档精度检查 3,963,138 个 query、15,852,552 个 query/head（四个路由组）：MBSA 差异 **0**；原生差异 **192**，每个差异恰好替换一个 block，比例 **1.21×10⁻⁵**。原生绝对差异是 10² 量级；两个档位分别统计，不把 graph、L2 和 overlap 的重复记录累加为独立差异。

性能每个组合预热 5 次，采样 19 次，CUDA events 和同步墙钟同时保存，cold L2 使用 256 MiB flush。BF16、prepared graph、warm L2、双方精度通过的 385 个原生 unified 同卡配对中，`native/MBSA` 时间比中位数为 0.6498，等价于逐对 `MBSA/native` 比值中位数约 **1.54**。严格路由精修增加成本，当前结果不能声称相对原生全面加速。完整档位、fallback 实际 BF16 精度与失败标记见 HTML。

修复包括 Fixed SWA 行级 mask、全局 packed Router、HF FP32 边界精修、capture stream 等待与 scratch 生命周期。连续 FP8 shape 的实验性 TMA Combine 未资格化，默认 FP8 使用已有 cp.async 路径；本次通过该默认路径完成全矩阵。此前失败与对照单独保存，不覆盖历史结果。24 项 GPU 测试全部通过、无跳过。

[源码审计](runtime-source-audit.json)保存两卡合同、CUDA 源码与图片哈希。测试期间本地 3 个 SM90/H100 文件有独立更新，另有两个独立 Sparse API 入口，已记录差异哈希；SM103 及测试入口一致。这些后续改动保留在工作区，本次 commit 使用已验证的快照。本次 B300 结果不资格化这些 H100/Sparse API 更新，H100 历史报告保持独立。
