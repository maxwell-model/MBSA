# Security Policy

## Supported versions

MBSA is currently in early development. Security fixes are provided for the
latest released version and the current default branch.

## Reporting a vulnerability

Please report security vulnerabilities privately through the repository's
GitHub **Security** tab. Include the affected version or commit, environment,
reproduction steps, impact and any suggested mitigation.

Please do not disclose a suspected vulnerability in a public issue or pull
request before the maintainers have investigated it. We will acknowledge the
report, coordinate a fix and publication timeline, and credit the reporter when
requested.
